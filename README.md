# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

当日校准口令做成一次性券：校准员在「口令台」生成当日券，提交校准时必须挂一张仍有效的当日券；入队成功该券即入作废簿，不得再次挂用。错券、隔日旧券、已作废券一律拒收。

|------|------|------|
| calibrator | calib123456 | 可发券、可挂券提交校准 |
| inspector | insp123456 | 只看（可翻口令台的有效券与作废簿，不可发券也不可作废） |

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 口令台生成当日券；挂该券提交超差样条，先待处理再出超差，该券随即记入作废簿。
3. 错券、隔日旧券、已作废券再投第二单均被拒收。
4. inspector 不能发券、不能提交，只能翻有效券与作废簿。
