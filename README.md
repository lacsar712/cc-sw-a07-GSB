# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

提交校准必须挂一张**当日校准口令券（一次性券）**：

- 校准员在「口令台」生成当日券；券当日有效，错券、隔日旧券一律拒收。
- 挂券提交入队成功后，该券立即记入**作废簿**，不得再次挂用（并发同券也只有一单成功）。
- 校准员可手动作废尚未使用的当日券，作废后同样不可再挂。
- 观察账号（inspector）只能翻阅有效券与作废簿，不许发券、不许作废、不许提交。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差；口令台可见当日券、隔日旧券与已作废券三态。
2. 在口令台生成当日券，回总览挂用提交，任务进待处理，随后出结论；同时该券从有效券移入作废簿（注明用于任务 #编号）。
3. 拿同一张已作废券再投第二单，被拒收；手填错券、挂隔日旧券、不挂券同样被拒收。
4. 在手动作废按钮把未用券作废后，该券不能再挂单。
5. inspector 登录只能看：发券/作废接口返回 403，总览无提交表单。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/coupons | 登录即可 | 有效券 + 作废簿（含 usable 标记） |
| POST | /api/coupons | writer | 生成一张当日券 |
| POST | /api/coupons/{id}/void | writer | 手动作废未使用券 |
| POST | /api/jobs | writer | 提交校准，body 必须带 `coupon_code` |
